# Timothy Street — Personal Website

A simple static landing page built with HTML, CSS, and a small amount of JavaScript.

## Publish with Netlify

1. In Netlify, choose **Add new project** and then **Import an existing project**.
2. Select **GitHub** and choose the `timothy-street/netlify` repository.
3. Leave the build command blank.
4. Set the publish directory to `.`.
5. Choose **Deploy**.

Netlify will publish future changes automatically whenever the `main` branch is updated.
